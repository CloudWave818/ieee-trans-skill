# ieee-trans-framework-style

把论文或方法文字自动提炼为用户参考图风格的方法框架图。

当前入口已改为先选择 [真实原图锚点](../../references/preferred_29/framework_anchors/INDEX.md)，迁移该原图的布局比例、字体、配色、机制图案与连线，再实际并排比较。下方历史单图保留为可选参考，不统一覆盖其他范本。

**输入真实方法，迁移视觉语法，不复制参考网络。**

## 文件

- `SKILL.md`：完整触发条件、内容提炼流程、科学连接约束、视觉规范与验收门槛。
- `assets/reference-framework-style.jpg`：用户提供的原始视觉参考；不是待复用的模型结构或实验结果。
- `templates/FRAMEWORK_SPEC.md`：绘图前由模型填写的内容与节点—连线规格。
- `templates/IMAGE_PROMPT_TEMPLATE.md`：将已提炼内容交给绘图工具的提示骨架。

## 使用指令

> 使用 ieee-trans-framework-style，阅读下面的论文或文字，提炼真实的输入、核心机制、分支与输出，直接绘制参考图风格的方法框架图。保持科学连接准确，不照搬参考图中的算法模块。

随后附论文或粘贴方法文字即可。只有简要文字也可以启动，图的详细程度应随证据调整。

## 与已有 ieee-trans-skills 的关系

可将本 Skill 作为“方法框架图”专用子模块，或合并其规则到原 Skill 的框架图分支。不用它替换已有的数据图、动机图或实物实验图规范。

本包没有修改远程仓库或现有本机 Skill。是否已注册为可自动触发的 Skill，取决于实际使用环境；本包提供可直接读取的完整内容与参考资源。

## 历史参考图的视觉特征

横向多阶段、浅色功能分区、细虚线组框、上置衬线标题、嵌套圆角模块、少量有科学含义的小图形、清晰真实的数据流、紧凑论文版式。

上述特征只描述历史可选范本，不是所有新图的默认要求或 IEEE 官方格式。当前布局由实际原图、科学机制和刊载位置决定。双栏论文框架总览通常跨栏，后续图按信息量混合单栏与跨栏；刊载宽度与横/方/竖画幅分别选择，不固定180 mm。颜色为参考视觉关系的近似设计值。
