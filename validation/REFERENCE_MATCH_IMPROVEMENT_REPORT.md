# 2026-10-02：从通用规则转到具体范本匹配

这次修订让给定主题或研究方案先匹配一篇具体论文，再实例化它的结构、句段职责、图组和实验组织。框架图先查看真实原图，保留它的布局比例、字体、机制小图和连线语法，再按新研究内容重画。

## 以后怎样执行

1. 主题或方案先选主论文，并分清已知信息、设计假设和缺失证据。
2. 主论文控制全文结构与阅读节奏；框架图另选具体主图，尽量沿用整套视觉语法。必要时只引入一个辅助来源，不平均混合全库风格。
3. 文字迁移段落操作，图形迁移构图和图案；机制、句子、文献与实验数据依据新项目重新建立。
4. Letter 压缩解释层和重复背景，保留核心接口与决定性验证；Transactions 展开实际新增模型、机制、分析和能力测试。
5. 实际渲染后并排比较，记录偏差；没有新渲染图时不能声称视觉验收完成。

## 随后针对图形质量的复查

用户指出首次试图仍不满意后，逐张重新查看八张真实原图及 R06 试图。首稿仅抓住了分区、浅色与外框；重复感知输出、把意图输出画成运算卡、大号简单无人机、反复红点/弧线、过重线框与回路，以及右下飞行器和障碍相交，均会实质影响观感与解释力。原先内部报告中的 MINOR 或相似度分数不构成用户所需质量的证明。详细原图优势、适用边界和首稿问题见 `references/preferred_29/framework_anchors/SELECTION_AND_CRITIQUE.md`。

本轮要求每次比较最接近的具体原图，按图的解释任务选型；同篇图组统一术语、字体、变量颜色、线宽与图注，不统一成一张框架。源图槽位无对应运算时删去或合并，不以重复状态或未定义算法填空。每幅机制小图须说明具体关系；未知内部保持明确功能块及接口。

检索也有实际偏差：整张锚点的“不要复制网络”等迁移禁忌曾被当作网络主题证据；仅 tracking/planner 的通用接口查询偏向 R06，非对称训练/部署查询偏向域梯度图 R23。已限制检索到源图观测内容，并返回可解释的机制与用途匹配：一般接口 R01、意图几何 R06、层级策略 R12、重置奖励 R20、域梯度 R23、非对称训练部署 R25、硬软动力学 R29 整图、软件功能分层 R29 子图。混合或只有宽泛关键词的请求仍需查看原图后决定，用户明确指定优先。

回归验证覆盖这些不同图目的和两组容易混淆的候选；参考资源与检索检查 275/275，通过，既有十个综合案例及 296 项结构检查通过。它们验证检索和资源，仍不认证视觉质量。当前测试方案只有功能级定义，尚无真实意图表示、预测或优化内部、项目实机照片，因此不能达到原图同等的科学信息密度；这一剩余差距应如实交付。

同一功能级跟踪方案实际重画为两个独立验证版本：工作区 `tmp/reference-forward-test-v2/` 是 R06 视觉语法版，橙/蓝各保留一个真实运算，减少重复输入和输出卡，采用不同作用的场景、预测、避障、可视和轨迹示意，重画符号平台并减轻文字与边框；`tmp/reference-r01-alternative/` 是 R01 简洁接口总览版，沿用白矩形、蓝色规划器容器和正交接口，未搬入原文的搜索、走廊或轨迹服务器。两者都有可编辑 SVG、实际 PNG、刊载宽度预览和与原图对照。root 查看了新渲染，要求修正 R06 预测示意穿障碍、标签压障碍以及无依据的人形目标；首稿保留以供对照。两版展示不同表达任务的选择，不作为所有后续论文的绘图模板。

## 2026-10-06：双栏论文的单栏与跨栏图组

用户指出现有图组过于依赖横向宽图。实际缺口是workflow06的“超过两个子图优先双栏”、示例连续采用180 mm宽图，以及规格中的栏宽没有贯穿导出与正文插入。框架模块没有固定180 mm的脚本要求，但README仍把历史横向范本描述为统一约定。

本轮将刊载跨度与横/方/竖画幅分开：密集框架通常横向跨栏，后续紧凑比较、消融、机制、轨迹和平台图先考虑单栏；是否扩大取决于信息与可读性，面板数量不单独决定跨度，也不设置比例配额。实际栏宽来自论文模板，未知时只用明确暂定尺寸。图组表、逐图模板与交接同时锁定最终毫米宽高、面板网格、字号与跨度理由；导出边界和实际插入尺寸须核对，单栏需要重排而非缩小宽图。布局需要可对范本作必要重排，但保留其表达语法。

更新接入主入口、图形工作流、style contract、框架子模块及两类交接模板、图表审计和自包含网页规划协议。演示图组改为5张单栏与3张跨栏的内容驱动规格；现有两张跨栏SVG草图保留，没有把尚未画出的单栏图标成视觉通过。

独立前向测试使用真实手稿与其前六张现有重绘图，只输出布局规格。在82.5 mm单栏、171 mm全文的测试假设下，根据内容得到3张单栏与3张跨栏；每张有物理尺寸、面板重排、绘图导出和正文插入合同。没有一律宽图、单栏直接缩图或强制紧凑框架跨栏。测试材料保留在工作区`column_layout_audit_20261006/forward_test/`，不随skill发布作者手稿或实验图。此结果验证规划可交接，不验证新尺寸成图的阅读效果。

测试还发现输入手稿与既有重绘件的部分图注/面板内容不一致；布局规格登记了同步依赖，工作流补充重排后的panel-ID映射及图注/正文调用核对。本轮没有替换手稿或重绘实验图。单栏密度、最终字号、长图注与页高仍须实际渲染和稿件PDF检查；结构、链接与skill格式检查不能认证这些未执行项。
