# 从一个题目生成具体图组：示范交接稿

示例题目：**面向动态障碍的深度视觉安全强化学习无人机导航**。

状态：`PROVISIONAL_FROM_TITLE`。这是假设性演示，不是用户已经实现的方法或实验。已知只有任务题目；以下策略接口、障碍估计和安全过滤均为可替换的设计假设。题目未指定期刊，保留 `UNDECIDED`。图形草图可立即执行；所有结果面板为 `NOT_READY / NEEDS_EXPERIMENT`。

## 论文先讲什么

暂定问题：视觉策略在动态障碍附近可能给出不安全指令。暂定改变：把障碍相对运动传入部署安全约束，用过滤器修改名义加速度。可观测后果：动态接近时，过滤前后指令有差异，实际间距/约束残差改变，任务进度与控制耗时也可能受到影响。待验证的主张是**安全与效率的权衡是否改善**，不是预先断言安全保证或领先性能。

借用 R25-F1 的训练/部署分区、R23-F3 的特权信息边界、R20-F2 的图案和闭环风格；用本例的实际动作接口展开源图省略的部分。飞行综合图借 R04-F14 与 R29-F6 的事件对应方式。

## 设计假设与替换条件

|项目|本演示选定的接口|若实际方法不同|
|---|---|---|
|感知/状态接口|深度图 D、自机位置 p、世界系速度 v、姿态 q、目标相对位置 g−p；位置/速度也用于障碍跟踪和约束构建；分辨率/编码器结构待实现确定|替换输入卡片及 encoder；不能无声加入部署没有的量|
|策略动作|世界系期望平动加速度 a_nom，单位 m/s²，不包含重力补偿|若输出姿态/推力或机体系量，必须新增并定义转换，不能仅改标签|
|安全过滤|障碍估计 p_o、v_o 及模型不确定性；约束求解器输出同坐标/单位的 a_safe|若使用奖励惩罚而无部署过滤，删掉 QP 支路与干预实验|
|控制|几何控制器把 a_safe 与指定偏航参考转换为总推力及机体系角速度命令|改为实际飞控接口，并提供频率、限幅、坐标定义|
|训练|暂用 PPO，不对称 critic 可访问仿真特权状态；actor 无特权输入|若不是 PPO 或不是不对称训练，替换训练带；不强行增加 critic 输入|
|失败处理|QP 不可行/超时触发 fallback；具体动作尚待定义|定义前不得声称部署可执行或安全保证|

## Fig.1：任务几何，不先画假结果

双栏 180×60 mm，三面板宽度 28%/34%/34%，间距各约 2%。(a) 深度输入示意、无人机、目标和动态障碍，标注数据是符号示意；(b) 无人机与障碍中心的相对位矢 d、障碍速度箭头和安全半径 r_safe；(c) 名义加速度 a_nom 与约束允许的 a_safe 两箭头，不画成功路径。颜色：策略蓝、障碍灰、危险边界橙虚线、修正后指令深绿。几何量与 Fig.2 变量一致。

图注只说明待解决的关系；不能写“有效避免碰撞”。本稿假设 h=||p−p_o||²−r_safe²，r_safe 的物理/估计裕量待定义，不把阴影面积解释成概率。

## Fig.2：可以交给绘图者的节点与接口

`VECTOR_SCHEMATIC`。双栏 180 mm，白底浅色分区，主链黑实线，训练梯度紫虚线。源色系来自 R25/R23，具体色值为本库近似迁移色。图内文字英语，正文说明中文。浅紫顶带约 23% 高度为训练，主部署链约 37%，底部约 30% 为反馈/约束细节；总高度以实际可读性为准。

|节点|内容与图案|输入→输出|
|---|---|---|
|N1 Depth + state|深度帧堆叠图案，状态向量短条|D,p,v,q,g−p → encoder；p,v 分支进入约束构建|
|N2 Encoder + actor|层叠特征块，不臆造网络层数|观测 → a_nom [m/s², world]|
|N3 Safety QP|浅蓝边框，内部写 minimize action change；标 constraint input 端口|a_nom、动态约束 → a_safe；status|
|N4 Controller|浅黄色，明确 gravity compensation inside|a_safe、yaw_ref → thrust / body rates|
|N5 UAV + scene|原生矢量四旋翼和障碍图案|控制命令 → 下一时刻观测|
|N6 Obstacle tracker|浅绿，两个时刻障碍中心和速度箭头|深度/状态历史 → p_o,v_o,uncertainty|
|N7 Constraint builder|浅橙，h 和相对运动小图|障碍估计、自机状态 → QP constraints|
|N8 Training critic + PPO|顶带，特权输入单独从仿真进入|rollouts / privileged state → policy update|
|N9 Fallback|文字接口提示，不假定具体制动策略|QP infeasible/timeout → action TBD|

正向边 N1→N2→N3→N4→N5；N5→N1 的反馈绕图底部走。N1 的感知历史分支进入 N6，N6→N7→N3；N1 的自机 p,v 另接 N7，使相对位移/速度有明确来源。N8 只用虚线更新 N2，特权状态不连到部署输入。N3 status 单独列出，不把 fallback 隐去。过滤器关于加速度的具体线性约束、障碍加速度模型和不可行处理尚缺，因此该草图是机制规划，**不是可以直接部署的控制算法说明**。

如果仅替换 PPO 为 SAC，主要接口不变；如果替换为 R05 的“捕获时间动作”，中下游结构必须重画。后者是检查图是否真正表达当前机制的一项测试。

## Fig.3：学习曲线

双栏 180×65 mm，两面板各 47%，共用方法图例。x 均为累计环境 transitions；(a) 固定 reward_eval 定义下的评估回报，(b) 固定终点距离阈值与时间上限下的评估成功率 %。使用同一 checkpoint 评估集，种子级均值；色带的具体统计方法在种子方案确定后填写，不预设已经有 CI。预训练/适配预算计入并标阶段。暂不规定基线名字和种子个数，避免伪造已完成实验；交接执行前这些字段必须由实验协议补齐。

日志 schema：`method,seed,checkpoint,phase,env_steps,wall_time_s,eval_set_id,episode_id,return_raw,success,collision,reward_eval_version`。元数据含 success_radius_m、time_limit_s、seed_plan、band_definition。若训练塑形奖励不同，不能拿各自 return_raw 直接比较；须用共同评估函数重新算。

空数据阶段不画任何上升曲线。执行后图注明确种子数、每种子 episode 数、阴影和平滑策略。

## Fig.4：最终性能

双栏 180×105 mm，2×2；同一固定测试集。(a) 成功率 %(越高越好)，(b) 碰撞率 %(越低越好)，(c) 任务完成时间 s，失败试验不可当成功时长，另报失败比例或有定义的截尾统计，(d) 感知到控制命令的延迟 ms 分布并画控制周期阈值。方法在纵向分类轴，禁止用不同排序暗示偏好。颜色/点形跨图固定。

收集 `method,seed,trial_id,scene_id,start_goal_id,success,collision,duration_s,termination,latency_ms`。置信区间的采样单位应考虑训练种子与试验嵌套，不把同一视频的帧当独立重复。图组未匹配到完全相同的范本，为 `MANUSCRIPT_DERIVED`，原因是要同时展示当前安全—进度—实时性主张。

## Fig.5：动态接近事件综合图

双栏 180×105 mm。左 54% 顶部 2/3：俯视 XY 轨迹（m）、障碍随时间位置和安全包络，标起终点与事件 E1 接近、E2 最大修正、E3 离开；左下 1/3 是同试验三个外部帧，没实拍时保留空位或改为明确标注的仿真帧。右 41% 三行时间轴：(a) 实际最小几何间距 m 与配置安全阈值，(b) ||a_safe−a_nom|| m/s²，(c) QP 状态/约束残差（分别用离散条或具定义的数值曲线，不能混同）。

同一事件竖线贯穿右三行，空间图上标同编号；要有相机时钟到日志时钟的映射。代表性试验选择：预先用固定测试集的路径长度中位附近试次并同时满足动态交互定义；如果挑失败案例另行标明，不挑最漂亮的成功图假称典型。

日志：`trial_id,t_s,p_xyz,obstacle_id,p_obstacle_xyz,a_nom_xyz,a_safe_xyz,min_clearance_m,qp_status,constraint_residual,frame_id,event_id`。还需 r_safe 定义、坐标变换、时间同步误差、帧率和采样率。多次试验的安全统计由 Fig.4 承担，本图仅解释一次行为。

## Fig.6：两处机制的消融

训练是否安全塑形 A×部署是否过滤 B 构成四条件 A0B0/A1B0/A0B1/A1B1。同一训练条件下打开/关闭过滤应复用同一 checkpoint；A 改变时重新按同一预算和种子计划训练。不要只比较完整方法与同时删掉两个模块的版本。

左 60%：横轴完成率 %，纵轴约束违反率 %，四条件点及独立种子散点/区间；右 35%：B1 两条件的每试验干预幅度分布。数据不足时不画 Pareto 边界。此布局为 `MANUSCRIPT_DERIVED`；R25 提供两处机制的启发，但不能据此声称原文已经做了这个完整因子试验。
