**摘要动作序列（p1 b2）**：非结构环境协作任务 → non-holonomic 团队规划 → 抓网接物过程的连续可微建模 → 它允许团队状态自适应变化 → 网尺寸与拓扑安全的几何约束 → 车式团队集成 → 仿真/实机 → 与 MVTP 比较效率和轨迹质量。多个约束不在摘要中一条条数齐，而围绕网的真实操作讲。

**引言逻辑链（p1 b4、b7；p2 b0–b1）**：复杂协作的想象性应用开篇 → 非完整/高维/强耦合导致精度与速度冲突 → 个体运动之外必须建模机器人—网—目标关系 → 接物状态自适应、网尺寸、网边不能被穿越三种实体条件 → 三者带来时空非凸问题 → 连续可微接物使梯度优化可用，几何约束保安全，稀疏表示/变量变换支撑在线 → 应用与基础 MVTP benchmark 分开 → 三贡献。

**篇章观察**：Collaborative Trajectories Optimization 先给通用轨迹优化，再由 Collaboratively Catching and Transporting Objects 给任务关系（p2 b5、p4 b12）；补充从 p9 开始，正文约八页，不能把补充推导误算成长文预算。
