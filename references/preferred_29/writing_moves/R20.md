- **摘要实际顺序（p1 b4）**：欠驱动与激进机动使潜力受限 → 规划/跟踪分离造成误差、延迟和初值敏感 → 状态和 aerobatic intention 直接输出命令 → 训练难度自适应课程 → 域随机化零样本迁移 → 移动门连续倒飞的具体实机事件。结果用演示任务作为核心锚点，不是一定要报平均性能提高百分比。
- **Introduction 功能段链（p1 b6、b8 → p2 b0–b3）**：飞行能力边界与高速大姿态任务 → 欠驱动和物理限制导致极小控制误差也危险 → 传统两阶段路线 → tracking error/latency/initial-value 三类缺点逐项说明 → 直接 RL 对应的机制优势 → 但固定初态+稀疏反馈又让学习困难 → progressive reset curriculum → 域随机化 → 动态实机事件 → 三条贡献。这一“解决老困难后出现新训练困难”的折返，比一直列组件更像真实研究过程。
- **篇章与引用**：一个 Methodology 大节内 Dynamics、RL Problem、Policy Optimization、Sim-to-real → Evaluations 先课程消融，再规划基线，再动态能力与实机。`[13]–[15]` 是自动课程思路来源；PPO `[20]` 是采用的算法，不列入原创贡献。
- **公式为何需要出现（p4 b1–b4，Eq. 7；b7–b8）**：yaw 奖励先给自然飞行/FPV 的目的，式后再明确它惩罚 body XY 面速度投影与机体 X 轴的夹角。课程段先解释状态距离不等于转移难度，所以不直接在状态空间随机采样；再引回动力学式与 flat-state 简化。数学选择都有对应理由。
- **结果的研究论证感（p6 b8–b11）**：课程、稀疏奖励、reward shaping 用原始目标评价，避免各自奖励定义造成不可比；规划基线不能在线应对移动航点，作者主动把直接 benchmark 限定到静态航点。不能把跨任务不可运行写成零成功率再宣称碾压。
