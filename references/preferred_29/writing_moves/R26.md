**摘要动作顺序。** VLA 的数据稀缺和静态表征两种局限 → video 作为语言到导航的统一接口 → 显式提出核心假说：时空/物理信息 + internet-scale 视频可支持零样本 → 随机生成风险要求采样选择 → 逆动力学解码可执行航点 → 新范式需要五维 benchmark → 实验/消融对假说的结论。这里 benchmark 是贡献，不是末尾随便补一个性能结果。

**Introduction 段落链。** 开放世界智能愿景与 VLM/VLA 现状；用数据 scaling 论据解释机器人为何尚未出现泛化跃迁，区分采集成本与多样性不足（p1 b7–b8）；静态图文表征又丢时序/物理信息（p2 b1）；视频模型因规模、时空描述、共享 state-action pixel space 同时回应两类局限（p2 b2）；把先前 manipulation decoding 难点与 navigation 的高层决策对照，说明为何值得在该任务试 video-as-planner（p2 b3）；然后才交代采样评价、π3 解码、outdoor scale recovery、执行与 benchmark；三项贡献为系统、资源、设计分析（p3 b0–b1）。它是“范式假说 + 可检验任务适配”，不是普通模块方法论文的同一套引言。

**篇章 / 引用 / 公式观察。** Methods 按 sampling optimization、scale recovery、planning 展开，Experiments 开头提出四个研究问题，Conclusion 后有独立 Limitation，再 References 与长 Appendix。p4 b3–b9 的 Φ 过滤 Eq. (1)、加权评分 Eq. (2)、argmax Eq. (3) 是筛除失败未来后再比较质量的两级决策，且写明无有效候选时需要人工决策。p4 b11→p5 b0–b6 从 π3 [40] 尺度不确定引入 Moge2 [41] metric depth，再给可靠范围 mask、pixel ratio 与 median consensus。引用贴着选用工具以及工具的特定不足出现。

**为什么像研究论证。** p6 b0、b16–b21 指出现有视频质量指标不等于导航指标，定义 visual consistency、dynamic feasibility、task completion；又明确 VLM 适合相对候选选择但不足以校准独立评分，所以基准改由有经验飞手打分。这是评价效度选择，不是实验配置说明书。p7 b0 又发现 LVP 的一致性/可行性分数高是因为保持静止，任务成功却低，指出这些指标的冲突与 ego-motion 训练先验差异；p7 b6–b7 则以尺度误差解释户外动作解码失效。不要继承摘要“physical laws”等超出实验证据的普遍断言；生成视频判定 collision-free 不是执行安全证明。
