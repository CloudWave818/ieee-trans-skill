**摘要动作序列（p1 b2）**：机载算力不足导致导航慢 → EARN/CMP → local 安全与 edge 效率的动态切换 → 现有方法忽视低层规划和高层资源分配相互依赖 → 资源约束下最大化 switching gain 的 MPS → bilevel MINLP/PDD 给可计算解法 → indoor/outdoor/real-world 证据 → navigation time 和 success rate。摘要从资源瓶颈起步，不浪费篇幅先说 robotics 广泛应用。

**引言逻辑链（p1 b3、b6；p2 b0–b4）**：导航计算随障碍、预测期、形状面数增加 → 已有算法侧减负方法 → 转向 collaborative computing 并用 narrow-gap 图示说明 edge 获得什么机动 → 三个实际挑战：低时延、服务器竞争、无服务器自主回退 → 因而必须联结规划状态/动作与切换/资源决策 → CMP/MPS 的研究问题 → 上层 binary 资源选择、下层 conditional avoidance、并行收敛求解分别对应挑战 → 仿真与实机 → 贡献及章节导航。

**篇章观察**：先一节提出 tightly coupled DMMP 的对象、接口和优化问题，再一节讲 algorithm design，Experiments 覆盖计算模型测量、多个基线、导航任务和实机（p2 b9、p4 b6、p6 b48）。它明确区分“求什么”和“怎么求”。

**引用观察**：state evolution 的具体系数不是重写一遍，而精确指到 [7, Sec. III-B] 的 Eq.(8)–(10)（p3 b4）；CARLA [29] 与 ROS bridge [30] 是实现来源（p6 b50）。长文也可引用细节以节省基础推导，把篇幅给新耦合问题。

**公式观察**：高/低频接口先说明（p3 b1）→ state evolution Eq.(1) → CMP Eq.(2) → conditional collision Eq.(3) → 解释 α=1/0 的两种行为及本地刹车回退 → switching gain Eq.(4)–(5) → 资源约束下 MPS Eq.(6)（p3）。不是定义 α 后停在“is the decision variable”，而是把二值开关导致的安全/效率行为写明。
