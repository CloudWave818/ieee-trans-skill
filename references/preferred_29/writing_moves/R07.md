**摘要动作序列（p1 b3）**：未知密集环境要求感知 → blind 机器人/群体困难 → 全员高成本传感器不经济 → 一架全感知 UAV 协助多个低感知 UGV → SLAM/共享地图/有限相对定位 → UGV 预测里程计与未知空间风险 → UAV 将动态支持需求变成 time-window routing 以缩短等待 → 仿真七车与实机三车验证。动机里成本与视点收益共同决定系统分工。

**引言逻辑链（p1 b6；p2 b0–b1）**：应用与感知依赖 → 多车 blind navigation 的成本 → UGV 负载/续航与 UAV 大感知范围的互补性 → 提出 mobile eye 协作问题 → 一个 UAV 无法一直看到所有车，RPE/FOV/遮挡先限定可用信息 → 共享地图中的 unknown cells 与轮速漂移造成规划风险 → UAV 必须为动态需求排支持顺序 → 地图和定位下发、风险上报、路由更新形成因果消息链 → 四贡献。

**篇章观察**：所有协作方法在一个 ColAG Framework 节内，按 Pose Estimation→Map Sharing→UGV Path Planning→UAV scheduling 展开（p3–p5）；没有强行独立 Preliminaries、Problem Formulation 和四个大 Method 节。短文靠消息链导航。

**引用观察**：引言 [7]–[9] 举出可用 RPE 途径，同时明确不采用依赖基础设施的全局定位；方法 [25] 承担已有轨迹生成；实验 [27] 承担模拟器（p2 b0、p4 b4、p5 b26–b28）。这些引用界定实现假设，不只是给泛背景句增加括号。

**公式观察**：EKF 状态、控制、transition、measurement 的 Eq.(1)–(7) 明确坐标变换与数据来源，特别说明 first observation 何时初始化（p3）；标准滤波器不是新贡献，却是后续 covariance-risk propagation 必须依赖的接口。

**像论证而非说明书的一处**：p4 b1–b4 先解释 UAV 视点遮挡让地图 unknown，若 unknown 一概禁行则效率低；因此 P-Map 激进规划，随后区分定位延迟和真实未知障碍两种风险，用 CP-Map 保守预测统一处理。一个设计带来另一项代价，下一设计才有必要。结果也承认 UGV 数量增加后等待变多（p6 b12）。
