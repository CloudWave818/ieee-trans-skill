**摘要动作序列（p1 b2）**：应用与目标预测必要性 → CV/constant-rotation 无法完整覆盖突转/减速 → 明确会失败的情形 → 意图语义带来稳健性/安全性 → potential+observation 的意图表示及 turning reachable region → intention-driven hybrid A* 未来位置 → intention-aware constraints 的优化 → benchmark 与实机。这里的缺口是一个既有假设在事件上的失效，不是“性能还不够好”。

**引言逻辑链（p1 b4、b14；p2 b18）**：理想跟踪应兼顾距离/FOV和突发动作 → 承认已有方法的 visibility/safety/smoothness 优点 → 指出 CV/rotation 缺少语义，配 T-intersection 遮挡例子和减速碰撞风险 → 意图方法的实时性与规划耦合两道问题 → 由状态/姿态识别到意图，再将意图变成搜索 primitives 与 transition cost，再变成优化约束 → 四项贡献，其中验证另列。

**篇章观察**：System Overview 后是 Target Intention Prediction、Intention-driven Target Motion Prediction、Intention-aware Trajectory Optimization 三节（p2–p5）。同一个“intention”沿表示→离散预测→连续规划逐层改变数学形态，而不是三次同义介绍。

**引用观察**：引言 [1]–[6] 支持成熟跟踪方法同时承认其长处，[7]–[15] 用来界定 data-driven intention prediction 的计算需求（p1 b4、b14）；方法用 BlazePose [19] 指明肩/髋关节测量来源（p3 b17）。“与已有工作不同”必须指向具体假设和场景。

**公式观察**：先由真实关节测量得到位置 Eq.(1) 与身体方向 Eq.(2)，再算方向相对速度的角度 Eq.(3)；环境可达扇区 Eq.(4)–(5) 支持潜在转弯，probability 抽象接口 Eq.(6) 后立刻落到真实选定意图与观察函数 Eq.(7)–(8)（p3–p4）。抽象函数之后必须实例化，不能停在 φ(module A,module B)。

**像论证而非说明书的一处**：转弯意图不是凭空声明概率函数；作者先观察靠近拐角时一侧可达区域扩大、转身时身体/速度夹角增加，再分别定义 potential 和 direct observation（p4 b0–b1）。结果也按转弯遮挡和减速距离两个失效分开解读（p7 b5、b20）。
