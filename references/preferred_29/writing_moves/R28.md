**摘要动作顺序。** 异构机器人互补价值 → rule-based 程序难理解开放语义 → LLM 推理机会 → VLM 补视觉 grounding → 现有方法仍依赖已知地图/集中同步 → 分散异步、紧凑共享、能力感知与统一动作接口 → 不经专门训练接已有 expert → 多场景/多 VLM 的成功和时间证据。这是从纯规则到语言再到视觉再到协作机制逐层加条件的摘要，不应删成“four modules”。

**Introduction 段落链。** 从并行/互补收益转到 task-specific 编程与自然语言的隐含约束；承认 LLM 与 VLM 逐层提高任务理解，再定位集中、同步、已知图和任务单一的限制（p1 b5–b6）；列四项具体挑战：任务分解、信息共享、异构互助、统一执行（p1 b6→p2 b20）；先给总的分散异步 loop 原则，再逐项解释 capability feedback、bounded mini-map、assist、expert execution 如何回应；限定仿真环境、两 UAV 一 mobile manipulator、无专门训练范围；给四条贡献（p2 b20–b22→p3 b0）。这篇确有“四挑战 → 四机制”清单式骨架，应保留对应关系但避免新稿照搬四项数量和 First/Second 全套句式。
