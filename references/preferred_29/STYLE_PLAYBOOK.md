# 以用户这 29 篇为主的无人机作图风格

适用：无人机、规划、控制、强化学习的图形设计。这里的优先级来自用户明确偏好，不是论文质量排名，也不是期刊格式规范。即便本 Skill 不负责 RA-L 短文写作，RA-L / arXiv / Nature 中的这些图仍可作为视觉参考。

## 先选机制，再模仿构图

给定题目或手稿，先检索 [INDEX.md](INDEX.md)，用 `python scripts/query_visual_cases.py "意图 预测"` 或 `"safety training"` 找 1–3 张关系相近的图。逐张读卡片；原页可用时核对需要迁移的部位。默认优先本库，旧库只补本库缺少的关系。不要用旧库的通用配色覆盖用户的偏好。

允许并主动模仿参考图的**层次、分区、配色关系、模块图案、连线语法、面板组合和证据顺序**。用本稿的对象和真实接口重新绘制。原图中的照片、测量曲线、专属机构或变量不能直接当成本稿的结果/机制；参考原图可以留在学习库中对照。不能只借论文编号而继续画任意风格的通用盒子。

每张关键图写清：`主要范本 → 具体借用哪些元素 → 本稿替换哪些对象/运算 → 哪些地方主动改进 → 对应数据/实验`。参考不是硬性配额，无匹配时允许 `MANUSCRIPT_DERIVED`。

## 可直接使用的色系与线条

以下色值是根据这批图的视觉关系选定的**迁移用近似色**，不是声称从论文源文件提取的精确色值。浅底用于分组，深色用于文字、线和关键强调。

|角色|浅底色|深色/线色|参考关系|
|---|---|---|---|
|状态/感知或 critic|`#E5F2E3`|`#397451`|R23 / R29 的绿色分组|
|策略/预测或任务规划|`#E3F0FC`|`#28628E`|R06 / R20 / R29 的蓝色分组|
|actor / 可学习模块|`#F8E4EC`|`#9C4B73`|R25 的粉色网络分区|
|采样/记忆/训练辅助|`#ECE5F7`|`#74569E`|R20 的重置与扩展分区|
|奖励/约束/形变规划|`#FBE8D5`|`#AA642B`|R20 / R29 的橙色分区|
|控制或重点决策|`#FFF3CC`|`#8A6F21`|R29 / R05 的浅黄分区|
|环境/共享模块|`#F0F1F3`|`#52616D`|白灰背景、黑灰前向连线|

同一篇论文内颜色语义固定。不要强求所有论文都用相同的“绿色=critic”：无 critic 的规划论文应按其机制重新分配，并在说明书给出图例。重要区别同时用文字、线型或符号表达。

默认白底；软色块配细边框；主箭头黑/深灰实线，反馈回路沿外围，训练反向梯度用有图例的彩色虚线。虚线也可表示训练专用边界，但不能同一层同时表示“未知”“无线”“梯度”而不区分。箭头标真正的数据/指令；分支从输出端发出，不从盒子中心穿过其他模块。转角和端口留空，长信号名换行或另设信号条。

图案应表达运算：图像输入画图像堆叠，点云输入画点集，CNN 可画层叠特征块，GRU 画带时间回环的单元，MLP 画小网络，优化器内画约束/目标的几何关系，安全过滤器内画名义与可行指令关系。它们不是装饰性贴纸。先确认本稿实际使用这些运算。

## 每张方法图都做“只换名字”检查

先填：旧方法在何处失败 → 我们改变的运算/约束/信息 → 改动前后输出差别 → 在实验中看哪个量。

例如安全屏蔽不是在 policy 后面加个蓝盒就结束。必须写 nominal action 的单位/坐标；若求解器用加速度，明确转换；障碍状态如何进入约束；过滤后什么指令给控制器；失败/不可行如何处理。实验要看约束违反、干预量、任务完成和耗时，不能只放回报曲线。

## 只有题目也能先给具体图组

直接生成有明确假设的 `PROVISIONAL_FROM_TITLE` 图组；不因为缺整篇手稿停在“请提供全文”。从题目识别任务、困难和可能的机制，区别**已知、设计假设、待作者确认**，先给每张图的布局、对象、变量、箭头、数据字段和删改条件。对会改变核心机制的未知点提供明确替换位置，不把假设写成作者既有方法。

可立即绘制空坐标、机制草图和面板框架。真实训练曲线/试验照片缺失时标 `NEEDS_EXPERIMENT` / `MISSING_INPUT`，不生成看似真实的趋势。见 [题目驱动示例](../../examples/preferred_uav_rl/PAPER_FIGURE_DESCRIPTION.md)。

## 图组与实际交接

一张主机制图只承担一条核心因果链；如动作接口、安全几何或机构细节太密，拆成伴随机制图。双栏组合图在约 178–180 mm 宽检查，单栏按实际模板约 85–90 mm；最终普通标签建议至少 7.5–8 pt，并用 `font_units × width_mm / viewBox_width × 72/25.4` 核算，不能只在屏幕放大看。

示例草图仅验证说明书能落到图形，不能代替用真实作者手稿进行独立绘图交接。保留草图、来源、发现的歧义和修正结果；结构验证通过不代表科学/视觉验收通过。
