# Query Examples

## UAV + MARL + cooperative planning; target TCYB; task experiment design

Prioritize domain tokens `UAV_AUTONOMY`, `RL_MARL`, `MULTI_AGENT_DECISION`, role `EXPERIMENT_ARCHITECTURE`, and journal `TCYB`. Expected shortlist starts with the retained TCYB multi-UAV exemplar plus cross-journal MARL/UAV experiment exemplars; return three, not the whole set.

## Distributed control + multi-agent; target TAC; task theory/formulation

Prioritize `CONTROL`, `MULTI_AGENT_DECISION`, roles `THEORY` and `PROBLEM_FORMULATION`, then exact journal. The TAC data-enabled predictive-control card and theory-led multi-agent cards should outrank system-only navigation cards.

## Robot navigation; task figure and real-world validation

Prioritize `ROBOTICS`, `NAVIGATION_PLANNING`, roles `FIGURE_ARCHITECTURE` and `REAL_WORLD_VALIDATION`, and evidence need `REAL_WORLD`. Return at most five only if both visual and deployment lessons are needed.
