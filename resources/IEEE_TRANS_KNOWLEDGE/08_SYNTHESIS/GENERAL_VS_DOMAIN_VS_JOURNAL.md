# General vs Domain vs Journal

Formal rule inventory: General 7; Domain 22; Journal-specific 13.

## Routing order

1. Load General Transactions rules that match the claim.
2. Add every relevant domain profile; overlapping domains are allowed.
3. Add the target-journal profile and let it resolve local evidence emphasis.
4. If a rule conflicts, prefer the narrower scope when its eligible population matches the paper.

## Promotion gate

A domain or journal tendency may become General only after cross-journal support, adequate sample size, counterexample review, and confirmation that the effect is not caused by paper-type composition.
