# Paper Type Routing

| Input identity | Load domains | Journal overlay | Evidence emphasis |
|---|---|---|---|
| UAV + MARL + cooperative planning | UAV_AUTONOMY; RL_MARL; MULTI_AGENT_DECISION; NAVIGATION_PLANNING | target journal | main comparison; robustness/generalization; runtime; physical validation if deployment is claimed |
| Distributed control + multi-agent | CONTROL; MULTI_AGENT_DECISION | target journal, especially TAC/TCNS when applicable | assumptions; stability/convergence; controlled simulation; application evidence |
| Robot system + trajectory optimization | ROBOTICS; TRAJECTORY_OPTIMIZATION; NAVIGATION_PLANNING | TRO/TMECH/TIE/TASE as applicable | formulation; algorithm; trajectories; runtime; physical system evidence |
| Autonomous vehicle + learning control | CONTROL; RL_MARL; NAVIGATION_PLANNING | TIV/TVT/TASE as applicable | safety/robustness; cross-scenario evaluation; latency; vehicle/platform evidence |

Routing is determined by the primary type plus every material secondary type in `PAPER_ANATOMY.csv`. Examples are executable routes, not fixed templates.
