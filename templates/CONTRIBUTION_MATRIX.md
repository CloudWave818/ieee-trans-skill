## Rejection screen

- “many experiments” used as contribution: YES / NO
- “integrated framework” without mechanism: YES / NO
- routine algorithm use presented as novelty: YES / NO
- unspecified performance improvement: YES / NO
- contribution disconnected from gap/challenge: YES / NO
