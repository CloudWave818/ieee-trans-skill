## Exit checks

- [ ] Every contribution-critical concept has one canonical name.
- [ ] No canonical name refers to multiple concepts.
- [ ] Every nonstandard acronym and symbol is defined before use.
- [ ] One-off terminology and unnecessary acronyms are removed or justified.
- [ ] Method names match equations and algorithm blocks.
- [ ] Ablation names match method modules.
- [ ] Metric, baseline, dataset, and condition names match tables and figures.
- [ ] Title, abstract, introduction, method, experiments, conclusion, and supplements use the same canonical terms.
- [ ] Every rename was applied globally and grammar-checked.
- [ ] All terminology conflicts are closed or marked `NEEDS_AUTHOR_DECISION`.
